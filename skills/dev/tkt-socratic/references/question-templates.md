# 代码场景苏格拉底提问模板

## 六类提问

### 1. 定义与概念
- 这个函数/模块的核心职责是什么？
- 是否单一职责？
- 有没有承担不该它管的事？

### 2. 假设与前提
- 输入假设是什么？
- 边界条件覆盖了吗？
- 空值、极端值、并发场景考虑了吗？

### 3. 理由与证据
- 有测试用例支持这个实现吗？
- 没有的话，是否先补一个再验收？
- 测试覆盖了多少分支？
- 有没有手工验证过关键路径？

### 4. 观点与视角
- 换个调用方视角，这个接口好用吗？
- 参数命名是否自解释？
- 返回值是否清晰表达了结果？

### 5. 后果与影响
- 这个改动会影响哪些下游模块？
- 会破坏现有 API 兼容性吗？
- 性能影响评估了吗？

### 6. 问题与目的
- 这段代码真正要解决的问题是什么？
- 有没有更简单的方案？
- 是否过度设计了？
